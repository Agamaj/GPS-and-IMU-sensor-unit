#    MPU-6050 – Gyroscope and Accelerometer
##    1. Component Description

The MPU-6050 (GY-521) is a 6-axis Inertial Measurement Unit (IMU) containing:

-    3-axis accelerometer
- 	3-axis gyroscope
-	Digital I2C communication interface

The sensor measures linear acceleration and angular velocity along the X, Y and Z axes.

In this project, the MPU-6050 is connected to a Raspberry Pi Pico W and programmed using MicroPython.

##    2. Hardware Specifications

| Parameter | Value |
|-----------|-------|
| Sensor | MPU-6050 |
| Module | GY-521 |
| Communication | I2C |
| I2C Address | 0x68 (default) |
| Accelerometer Range | ±2g, ±4g, ±8g, ±16g |
| Gyroscope Range | ±250, ±500, ±1000, ±2000 °/s |
| Supply Voltage | 3.3 V (module connection) |
| Microcontroller | Raspberry Pi Pico W |
| Programming Language | MicroPython |

##    3. Hardware Connections

| MPU-6050 Pin | Raspberry Pi Pico W | Physical Pin |
|--------------|---------------------|--------------|
| VCC | 3V3 OUT | 36 |
| GND | GND | 38 |
| SDA | GP4 (I2C0 SDA) | 6 |
| SCL | GP5 (I2C0 SCL) | 7 |

The sensor communicates with the Raspberry Pi Pico W using the I2C0 interface.

##    4. I2C Communication Test

The I2C interface was initialized using:

-	I2C controller: I2C0
-	SDA: GP4
-	SCL: GP5
-	Frequency: 100 kHz
-	Expected device address: 0x68

The sensor successfully communicated with the microcontroller, allowing acceleration and gyroscope data to be read.

##    5. Sensor Testing

The MPU-6050 was tested using a MicroPython program.

The program performs the following operations:

1.	Initializes the I2C communication.
2.	Wakes up the MPU-6050 sensor.
3.	Reads acceleration and gyroscope registers.
4.	Converts raw sensor data into physical units.
5.	Displays measurements in the terminal.

###    Measurement Units

**Accelerometer:**
-	X, Y, Z axes
-	Unit: m/s²
**Gyroscope:**
-	X, Y, Z axes
-	Unit: degrees per second (°/s)

##    6. Experimental Results

The following values were obtained during the initial sensor test.

###    Accelerometer Measurements

| Axis | Measured Value | Unit |
|------|----------------|------|
| X | -0.29 | m/s² |
| Y | -0.14 | m/s² |
| Z | 9.42 | m/s² |

###    Gyroscope Measurements

| Axis | Measured Value | Unit |
|------|----------------|------|
| X | -4.57 | °/s |
| Y | 0.46 | °/s |
| Z | 1.03 | °/s |

##    7. Results and Evaluation

###    Accelerometer

The accelerometer measurements are consistent with a sensor positioned approximately horizontally.
The Z-axis measured 9.42 m/s², which is close to the theoretical gravitational acceleration of 9.81 m/s².
Small differences may be caused by sensor offset, calibration errors or slight sensor inclination.

###    Gyroscope

The gyroscope returned non-zero angular velocity values during the measurement.
The X-axis measured approximately -4.57 °/s.
If the sensor was stationary, this indicates a possible gyroscope offset.
A calibration procedure is planned to improve measurement accuracy.
